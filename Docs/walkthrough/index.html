What Atlas is

A governed AI data platform for regulated banks. It reads the estate's metadata, enforces policy before any action, explains every result it produces, and turns safe, repeated analysis into reusable tools. Models propose; the platform decides, and a second person approves anything that changes what an agent may trust.
