Ready to demo, not ready to deploy

An honest read of where Atlas stands: the work queue counted, production controls scored against the code, and what to say and not say in front of an audience.

Verdict

Demo: yes, on a private machine. The governed-metadata story works end to end on the seeded Northwind estate: catalog, lineage, stewardship with maker-checker, governed SQL, and the role behaviour on the next page. Sixteen roles were probed live and the running API matched the declared contract on every check.
Production for a bank: not yet. It fails closed in code and is honest about its gaps, but no real identity provider, secret manager, archive or SIEM has been exercised, there is no backup or DR, no deployable topology beyond an API sketch, and no independent security or scale evidence. A pilot needs the first five blockers below; a full go-live needs all ten.

Go-live blockers, in order

  1. Identity and secrets on a real bank. No real IdP or secret manager has been driven (R11-B6, decisions BD-1 and BD-3). Close with it: HTTPS on issuer and vault URLs, a readiness probe of both, and a non-static vault login (the JWKS refetch cooldown and outage backoff are done).
  2. No deployable topology. Nothing beyond an API sketch; no image build, push and sign pipeline; nothing applied to a cluster.
  3. No backup, restore or DR, and no drill (BD-7, R11-B15). Six of eight drills in the tracker have never run.
  4. Audit evidence is not immutable by default. Archive off, tables mutable by the application role, no separate migration role; SIEM off or unverified against a real destination (BD-9, R11-B9).
  5. No security assurance. Penetration test, break-glass and deployed revocation evidence are blocked (R11-C9); no SAST, DAST, container scan or signing.
  6. Transport and edge. No TLS in shipped artefacts; no HSTS or CSP; /metrics, /docs and readiness open on the API port; no network policy; no REST rate limit.
  7. Workspace authorization is observe-only. It ships non-enforcing, an operator must flip it, and no queue row tracks that.
  8. Capacity unmeasured at scale (R11-B15). At its ceiling each process opens 30 database connections: the three default processes reach 90 of the 97 usable on a stock PostgreSQL, and all five would need 150.
  9. Alerts route nowhere, and delivery, archive and auth-failure signals are not metrics.
  10. Model residency, monitoring and masking licence (R11-C11, R11-C13). SOC 2 and ISO are not started.

Before you demo

The stack matches the code. It was rebuilt on 2026-09-22 at 11:16 from a clean worktree of the source cf835e7 carries (built as 4f15579, the same three commits before they were replayed onto a peer's documentation commit), and scripts/check_deployment_parity.py reported 9 of 9 comparisons matched (source digest 7f50718814af). Documents after it are outside the digest. On this build: the role checks (7,952 probes, 0 failures), the read-route sweep (2,496 calls, 0 server errors), the accessibility audit (40 screens, 0 violations in either theme) and the rehearsal (50 screens, 0 issues, 5 known conditions). If HEAD has moved since, rebuild from a clean worktree and rerun the parity check first.
  • Keep it off shared networks. Every service port binds to all interfaces with default passwords, and X-Roles: PlatformAdmin on port 8000 grants admin. The UI bakes in an all-roles development identity.
  • Ask sends prompts to real providers. The deployed API holds live OpenAI and Gemini keys and the approved route is labelled residency development. Demo without live generation, or decide deliberately that prompts may leave the machine.
  • Rotate the Gemini key, and keep container logs off the screen. The scheduler printed it into its log (R11-AUD14). It no longer does, but a log written before the fix still holds it.
  • Do not press: the organization kill switch's Engage (alex), the per-agent Kill in the Agent inbox (sam or alex), Approve in Riya's queue outside the loop, or anything on notification delivery. Omar's Review queue and vic's Agent inbox answer 403 by design; stay on the script.
  • Freeze the working tree while presenting. The eight per-user UIs are Vite dev servers that hot-reload whatever a peer session saves; restart them from a clean checkout if other sessions are active.
  • Leave notification delivery alone. Nine governance notifications have been retrying since 2026-09-12, at up to five attempts each. Enabling or changing the delivery worker would start delivering or dead-lettering them.
  • Say what is not proven: no WORM claim (archive status is NO_ARCHIVES), no alerting claim (no Alertmanager), no HA, DR, scale or p95 claim, and do not call workspace authorization enforced: it is observing.
  • Authentication claim. The local stack trusts identity headers by design. Say so, then show the OIDC overlay if the audience needs the production shape.
