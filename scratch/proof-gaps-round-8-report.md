# Round 8: ST-01 (Target Structure + Module Template) Done

## What this delivers

Tracker exit criterion for ST-01 is "Generated module passes all contracts." That's now demonstrated concretely.

**`scripts/generate_module.py`** — a module template generator. Given a lowercase snake_case name, it scaffolds the full module anatomy from `Docs/10-architecture/04-module-decomposition.md` §7 under `src/atlas/modules/<name>/`: `__init__.py`, `api.py` (public interface), `contracts.py` (public DTOs), `router.py` (HTTP routes, unmounted), `service.py` (domain logic), `models.py` (private ORM), `schemas.py` (private request/response models), `repository.py` (private data access), `events.py` (domain events), `workers/`, `migrations/` (with a README noting Alembic wiring is separate, later work), and a `tests/` directory that runs standalone. It knows the module→schema name exceptions from §6 (e.g. `identity_tenancy` → schema `identity`) and refuses to overwrite an existing module unless you explicitly pass `--force`, so re-running it later can never silently clobber a module that's since been populated with real code.

**`src/atlas/`** — the empty target-structure container itself: `platform/` (empty, per Phase 0 of the refactor plan — "build the container before moving anything into it") and `modules/`.

**`src/atlas/modules/identity_tenancy/`** — one real generated module, as the concrete proof the generator and anatomy actually work. I picked identity/tenancy because it's module 01 — first in the Phase 3 extraction order in your own refactor plan. Every file is explicitly marked "scaffold only (tracker ST-01)" in its docstring; no behavior has moved into it. That's deliberate: Phase 0 is scaffolding, not extraction — moving the real `security.py`/`oidc.py`/`secrets.py` logic into this module is Phase 3, a separate, bigger, higher-risk step.

**Two test files** (30 new tests total):

- `tests/test_module_scaffold_generator.py` (12 tests) — exercises the generator itself against temp directories: full anatomy produced, generated Python is syntactically valid, refuses to clobber an existing module without `--force`, rejects malformed names, the generated scaffold already satisfies the module-privacy rule (public files never import private ones), the schema-name aliasing works, and the output is a real importable Python package.
- `src/atlas/modules/identity_tenancy/tests/test_module_scaffold.py` (2 tests) — the module's own self-check, generated by the tool itself, proving `pytest src/atlas/modules/identity_tenancy` runs standalone per the anatomy's own requirement.
